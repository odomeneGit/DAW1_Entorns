# M05 · Entorns de desenvolupament — RA2

Teoria web sobre l'ús d'Eclipse IDE for Java Developers 2025-06 (4.36.0), amb captures reals de la configuració i dels exemples de projecte Java i Maven.

## Contingut
- Funcions d'un IDE
- Entorn de treball i workspace (sense instruccions d'instal·lació del sistema operatiu)
- Creació guiada d'un projecte Java i d'un projecte Maven
- Estructura, `pom.xml`, identificadors Maven i tasques bàsiques
- Interfície real d’Eclipse, recuperació de vistes i restabliment de la perspectiva
- Ressaltat de sintaxi, Content Assist i Quick Fix
- Depuració
- Personalització i plugins
- Exportació d'un projecte en ZIP per lliurar-lo i importar-lo, exportació d'un Runnable JAR, automatització i repàs

Les captures dels assistents Java i Maven provenen de l'entorn real utilitzat per preparar l'exemple. Obre `index.html` per accedir al web o `ra2.html` per consultar directament el RA2.
